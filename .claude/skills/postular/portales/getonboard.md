# Get on Board

Lecciones de postular en este portal. Léelo después de `SKILL.md` si la vacante es de Get on Board.

- **Aviso de coincidencia baja** (Get on Board muestra «Low match» con «Apply anyway» antes del formulario): es una advertencia del sitio, no un bloqueo. El enlace abre el formulario sin enviar; incluir el aviso en el resumen de la confirmación de envío.
- **Subir un CV nuevo**: el campo de archivo solo recibe el PDF con el modal «Upload a new resume» abierto; subirlo antes no lo adjunta. Después de cada «Next» la página se reacomoda: relocalizar con `find` antes del siguiente clic para no caer en otro campo.
